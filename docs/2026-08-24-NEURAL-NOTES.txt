Head 3 might focus on the topic of the sentence: "What is this sentence about?"

softmax: a math tool in machine learning. It takes a list of raw numbers and turns them into a set of probabilities. Each output number is between 0 and 1, and all the numbers add up to 1

LayerNorm: a deep learning technique that normalizes inputs across the features of a single training example rather than across a mini-batch. It stabilizes hidden states, prevents vanishing gradient

FFNs act as associative memories:

The first layer acts as a key lookup: "What pattern does this input match?"
The second layer retrieves the value: "What output should I produce?"
So the FFN stores knowledge that the model has learned:

Factual knowledge ("Paris is the capital of France")
Linguistic patterns ("The cat ___ the mouse" → "chased")
Semantic relationships ("happy" → "joyful")

logits are the raw, unnormalized scores output by a model before an activation function (like softmax or sigmoid) turns them into probabilities. They can be any real number from negative to positiv
So basically, logits are the model's raw predictions, and softmax turns those predictions into probabilities that sum to 1.
